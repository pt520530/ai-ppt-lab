# 高質感 PPT Prompt

用於產出高端、圖片導向、低文字密度的商務簡報初稿。

## 高級圖文版 PPT 固定提示詞模板

請依照以下欄位，先產出「純文字 HTML 校對版」，不要一開始生成 PPTX。

### 基本資訊

- 簡報主題：
- 簡報目的：
- 目標觀眾：
- 頁數：
- 整體風格：高級圖文版、深藍金色主視覺、滿版高質感圖片背景、大字、粗體、少字。

### 每頁內容規格

請針對每一頁整理以下欄位：

1. 頁碼：
2. 每頁主訊息：
3. 每頁標題：
4. 每頁副標：
5. 每頁最多 3 個輔助重點：
6. 圖文配置建議：左文右圖 / 右文左圖 / 上圖下文 / 滿版背景加文字區。
7. 是否需要滿版圖片背景：是 / 否。
8. 是否有主視覺人物 / 產品 / QR Code：請標明位置與不可遮擋區域。

### 固定輸出流程

1. 先輸出純文字 HTML 校對版，方便阿君檢查標題、副標與每頁文字。
2. 不要一開始生成 PPTX。
3. 不要自由改風格，必須維持高級圖文版、深藍金色、滿版圖片、大字少字。
4. 等阿君確認文字後，才進入 Codex 施工規格。

### HTML 校對版要求

- 每頁用一個清楚區塊呈現。
- 只放文字、頁面目的、圖文配置建議與視覺注意事項。
- 不需要精緻設計，不需要動畫，不需要產生正式 PPT。
- 若資訊不足，先列出需要阿君補充的問題。

### Codex 施工規格啟動條件

只有在阿君明確確認文字內容後，才開始整理可交給 Codex 製作 PPT 的施工規格，包括版面、圖片需求、文字區位置、字級、配色與輸出檢查清單。
