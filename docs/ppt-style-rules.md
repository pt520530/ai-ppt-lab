# PPT 風格規則

記錄高質感 AI 簡報的基本版面、字體、配色與圖片使用原則。

## 適用範圍

本文件適用於「阿君 AI PPT 與海報工具庫」中的高級圖文版 PPT、活動簡報、課程簡報、顧問提案與品牌展示頁面。

## 高級圖文版 PPT 排版硬規則

1. 主視覺以深藍金色為核心，整體要有高端、穩重、專業感。
2. 每頁優先使用滿版高質感圖片背景，不使用空泛裝飾圖。
3. 文字採大字、粗體、少字原則，避免塞滿段落。
4. 一頁只講一件事，主訊息必須一眼看懂。
5. 主標字級 44pt 以上，必須清楚、有重量感。
6. 副標字級 28pt 以上，用來補充主標，不搶主標焦點。
7. 內文字級 24pt 以上，只保留必要資訊。
8. 文字不可遮住人物、產品、QR Code、主要光源或圖片核心視覺。
9. 圖片與文字必須分開處理，不用 SVG 整頁封裝，方便後續編輯。
10. 先判斷主視覺位置，再決定左文右圖或右文左圖。

## 視覺與版面

- 深藍色負責建立專業感，金色用於重點、線條、標記與關鍵數字。
- 背景圖片要清楚、有質感，人物、產品或場景不可被裁切到失去重點。
- 若圖片主體在右側，文字優先放左側；若圖片主體在左側，文字優先放右側。
- 文字區需要有足夠對比，可使用半透明深色遮罩，但不可破壞主視覺。

## 文字規則

- 每頁主標只保留一句核心訊息。
- 副標只補充背景或承諾，不重複主標。
- 內文最多保留 3 個短點，能刪就刪。
- 避免使用長句、密集表格與小字註解。

## 輸出檢查

- 遠看是否 3 秒內看懂主訊息。
- 字是否夠大，手機截圖也能讀。
- 圖片主體、產品、QR Code 與光源是否完整可見。
- 文字、圖片與版面元素是否能在 PPT 中單獨編輯。
